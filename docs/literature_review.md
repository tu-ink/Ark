## 1. 选题背景与意义

随着网络规模扩大，DoS、扫描探测(Probe)、远程入侵(R2L)、本地提权(U2R)等攻击
持续演化。传统基于特征库/规则的检测对未知攻击与加密流量乏力，而人工智能技术
能从高维网络流量中自动学习攻击模式，已成为入侵检测与主动防御的主流方向。
本项目围绕“**AI 检测 + 智能防御联动**”构建可运行的网络攻击检测防御系统原型。

## 4. 文献要点归纳（与本项目的对应关系）

1. **检测方法演进**：传统机器学习（决策树/SVM）→ 深度学习（DNN/CNN/LSTM/注意力），
   深度方法在高维流量特征与隐藏模式提取上优势明显（文献 1）。
   → 本项目提供 RF（机器学习基线）与 MLP（神经网络）双模型对比，便于演示两类方法。
2. **数据集与评测**：NSL-KDD（约 25 万样本、难易适中、无冗余）→ CICIDS2017
   （更接近真实网络）。评估普遍报告 Accuracy / Precision / Recall / F1、混淆矩阵与 ROC-AUC。
   → 本项目兼容 NSL-KDD 格式，内置五分类与 AUC 等指标（文献 1、6、7）。
3. **检测难点**：R2L/U2R 类攻击流量与正常流量高度相似、样本极少，检出率偏低；
   数据不平衡是公开难点（文献 1、8）。
   → 本项目演示数据中特设约 18% “伪装成正常流量”的隐蔽攻击硬样本，
   使模型呈现接近文献描述的“检出率 ~0.83 而误报极低”现象，见 docs/experiment.md。
4. **智能防御与对抗**：AI 用于防御的同时也可能被对抗样本绕过（文献 2）；
   检测系统需与封禁/阻断/溯源等响应能力结合形成闭环。
   → 本项目在检测外实现了“置信度+滑动窗口证据累积”的自动封禁防御引擎，
   并把“对抗鲁棒性”“在线学习”列为后续扩展点。
